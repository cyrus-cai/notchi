## Install via Homebrew

```bash
brew install --cask cyrus-cai/lofi-lab/notchi
```

Or copy a prompt for Claude Code:

> Please install Notchi for macOS for me. Run this in my terminal: brew install --cask cyrus-cai/lofi-lab/notchi
> It is a free, open-source menu-bar app (https://github.com/cyrus-cai/notchi). After it finishes, confirm Notchi is installed in /Applications and launch it.

## 100% in your control

- **Local data** — Chats and memory stay on your Mac
- **No sign-up** — No email, no password
- **Bring your own key** — Connect your model provider directly, without Notchi in between
- **Auditable requests** — Settings → Audit lists every request Notchi sends
