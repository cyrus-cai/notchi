## 用 Homebrew 安装

```bash
brew install --cask cyrus-cai/lofi-lab/notchi
```

或复制给 Claude Code 的安装指令：

> Please install Notchi for macOS for me. Run this in my terminal: brew install --cask cyrus-cai/lofi-lab/notchi
> It is a free, open-source menu-bar app (https://github.com/cyrus-cai/notchi). After it finishes, confirm Notchi is installed in /Applications and launch it.

## 100% 由你掌控

- **数据留在本机** — 对话和记忆仅存于本机
- **无需注册** — 无需邮箱和密码
- **自带 API Key** — 支持直连模型服务商，不经过 Notchi
- **请求可审计** — 「设置 → 审计」列出 Notchi 发出的每个请求

[在 GitHub 上开源 ↗](https://github.com/cyrus-cai/notchi) · [隐私政策 →](https://notch.website/privacy)
